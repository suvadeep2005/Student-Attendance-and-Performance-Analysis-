# Student attendance and performance analysis
##project overview
This project analyzes student academic journey using python and power BI.
## OBJECTIVE
The objective of this project is to simplify the analysis of student attendance and academic
performance through an interactive dashboard. It helps users explore attendance patterns,
compare academic results, and investigate the statistical relationship between attendance and marks.
## TECHNOLOGY USED
* **Python** – Core programming language used for data analysis and application logic.
* **Streamlit** – Web framework used to build and host the interactive dashboard.
* **Pandas** – Data manipulation library used for reading CSV files, filtering records, calculating metrics, and generating pivot tables.
* **Streamlit Option Menu** – Third-party component used for creating the custom sidebar navigation menu with icons.
* **Power BI** – Business intelligence tool used for additional data visualization and reporting.
* **CSV (Comma-Separated Values)** – Structured dataset format for student attendance and academic performance records.
